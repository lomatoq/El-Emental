# R1 source audit and exact validation protocol

R1 was explicitly authorized after a read-only audit. Sources refrozen after this revision; actual Assets/Unity untouched. Before shader SHA remains fdffcdacfb3c18d6904b0bf125d7d8cb2595328d702fb8f60ae65b6a71281ec0.

## Material defects fixed

1. Art previously bypassed protected opaque masks. Example: camera (0,65,2200), bank2 around(-120,-70,1500), ray aimed at planet. Bank intersection is beyond300m and in front of planet, so depth alone allowed art over an otherwise protected planetary surface. Cloud alpha now multiplies the same camera-clear and planet-radius protection as haze. Opaque region inside planetRadius+80m has exactly zero art overlay at any observer distance.
2. Art previously remained bright through optically opaque lower fog. Observer50m below veil with1500m travel to a bank at veil height produces finite path transmittance exp(-37.5)=5.1756e-17. Cloud alpha now uses that same analytical transmittance, rather than only a cosmetic distant-color tint. A cloud650m away at250m above veil retains0.993446 transmittance, so upper lobes can remain readable while their bases dissolve into the veil.
3. ForcedLOD0 discarded mip filtering and risked distant/oblique shimmering. Cloud UV gradients now evaluate before any pixel-varying early rejection, and SAMPLE_TEXTURE2D_GRAD uses them. The actual generated texture importer currently has mipmaps enabled, sRGB input, clamp wrap and transparency enabled. A zero horizontal bank normal is safely rejected instead of normalized to NaN.

Four current Unity Roslyn assemblies compile with zero errors. Initial recompilation of stale response files failed because geometry owner had added RockShapeBuilder; regenerating response files from current Bee inputs resolved this unrelated overlay freshness issue. R1 numerical equation checks passed. Twelve NUnit cases are staged, not executed. GPU shader compilation remains unverified.

## Edge cases reviewed, no additional source change

- Sky integral is infinite spatially, not an unbounded loop. Downward and horizontal rays approach opaque veil even when camera far clip cannot reach the plane. Upward rays use the convergent exponential integral; limiting opacity tends continuously to1 as upward slope approaches0 for positive density. Density0 remains clear.
- Cloud intersection has a separate finite12000m sky bound and a30m end fade. This deliberately limits artwork; it does not truncate sky fog. Current bank positions650–1500m and normal gameplay envelope do not approach that boundary. External QA moving farther than12000m can reveal disappearing artwork while fog remains, which must be treated as out-of-profile until tested.
- The authored frame is a zero-offset child of the explicit planet. Publication strips inherited scale, using its world rotation and position. Under those invariants, reconstructed local surface length is distance from planet center, and translated/rotated planet poses preserve protection. Manual translation of the frame away from localzero or changing planet scale/radius without Configure invalidates that invariant; installer does not perform those operations. Include a transform audit after integration.
- Fog/texture/source compositing stays in the existing Gamma render-target convention with straight alpha; no extra gamma conversion/premultiplication was added. Artistic color mixing is not claimed as physically linear radiative transfer. Linear/project-color-space migration remains separate.
- Source opacity and opaque sunlight cue are preserved. Original atmosphere branch is intact when disabled. Vignette darkness0.2 and existing seismic/postprocess still execute outside V2. Original branch comparison is therefore a proper feature comparison, but fine art can remain obscured by other custom blur.
