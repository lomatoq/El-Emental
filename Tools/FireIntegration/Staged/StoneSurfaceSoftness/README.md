# Stone surface softness / fracture continuity

Evidence from actual saved materials: exterior and interior are identical; both BaseMap references null, VertexFaceTone0, MatchFractureSurface1. Therefore visible dark planar cut patches cannot currently be UV texture seams, green vertex tint, or FractureInteriorDepth (masked out by MatchFractureSurface). Geometry normals, cast shadows and SSAO are the plausible visible sources. Actual daytime screenshot has strong planar face changes; exact per-pixel contribution requires lighting/debug A/B in Unity, not a guessed UV repair.

Changes are three files only. Shared orange palette, geometry, colliders, vertex data, additional-light variants and all gameplay remain untouched. Both materials receive same small tuning: ShadowFloor.56→.66; AO strength.68 instead of unbounded full SSAO multiplication; facet contrast.16→.12; bevel light.2→.13; roughness.92→.96. Other materials retain original AO via property default1. MainLight cast shadows/contact cues remain; no smoothing of authored face normals or removal of shadow reception.

Sunset screenshot exposes a separate mismatch: cloud/fog palette is bright while direct sunlight disappears, and Rumble uses SampleSH plus a very small ambient term without explicit twilight bounce. Added opt-in rock-only twilight ambient floor.18, using actual solar altitude with same horizon envelope as cloud palette. It is exactly zero at noon and deep night; character shaders/materials remain unchanged, so black character at sunset still needs its own lighting-owner diagnosis. No global lighting or ambient settings changed.
