# Far artwork / procedural cloud visibility correction

The controller used 1000–1800 m, while curated islands are approximately 550/800/1100 m from the camera. The far mask was exactly zero below 1000 m and only 0.043 at 1100 m. It was also multiplied by upper-playable-cap height, suppressing lower portions of distant columns unnecessarily. Changed range to 600–1100 m: 550 m remains untouched, 800 m weight .352, 1100 m full. Existing explicit near-range and planet-radius guards remain. Removed only the inappropriate upper-cap multiplier from far artwork. Fog protection itself is untouched. Positive-only chromatic edge strength .42→.58; 1.3px shift at 1080 unchanged. Stipple remains within the existing .018 authored strength and no black grain, with slightly more uniform visibility.

Current procedural bank attenuation is not the primary invisibility cause: banks above the veil transmit nearly fully. Their old centre elevations placed them around 1–5 degrees above the camera, behind image cloud strips and pillars. Raised banks to 290–650 m at 1.5–2.9 km, thickened from180–250 to260–330 m, shifted rear banks into the actual menu viewing corridor. Still six draws/12 samples, no additional cloud layer or image edits.
