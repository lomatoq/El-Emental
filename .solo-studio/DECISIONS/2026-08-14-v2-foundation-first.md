# Decision: V2 foundation-first execution

Date: 2026-08-14  
Status: accepted

The V2 package explicitly requires Phase 0 and Phase 1 verification before Quick Cast, Wave V2, Surf or broad polish. Baseline evidence confirms the foundations are the decisive constraint: daylight is black, the camera hides ground action, and wall emergence animates a Rigidbody/collider into the planet.

Implement the asset gate, stable visual-only wall emergence, readable day sky, Camera V2 first pass and locomotion runtime proof as one vertical slice. Continue to Phase 2 only after fresh tests, build and visual evidence pass.
